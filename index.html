Check the basics

Power, paper, ink/toner, USB cable or Wi-Fi light. Print a config page from the printer's own menu.

Find the IP

Run arp -a and match the printer's MAC address from its label or config page.

3

Test the connection

ping 192.168.1.50 — replies mean the printer is reachable on the network.
